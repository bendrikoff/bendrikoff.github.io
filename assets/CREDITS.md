The jam explicitly requires the main Dogelon character sprite and permits adapted versions. Dogelon artwork remains the property of its respective owners; this project does not relicense it.

Game concept reference: Planet Hopper by @justjonny, https://remix.gg/g/planet-hopper. The three-lane jumping and mission-selection concepts were observed from play. No source code, artwork, audio or level data from Planet Hopper is included.

World geometry, procedural environment textures, UI styling, track generation and synthesized sound effects were created for this project. The playable character uses the supplied model credited below; the original sprite remains in the source assets for reference.

Three.js 0.180.0 is bundled locally under the MIT license. The distribution includes `THREE-LICENSE.txt`. esbuild is used only during development to produce the standalone browser bundle.

Playable hero: user-supplied Shiba_Astronaut_Animated.glb from e-x20/outputs (2026-09-15). Original embedded Shiba_Color_Atlas, 17 materials and five skeletal animation clips preserved. Game uses Jump_Left / Jump_Right for moves and Idle for waiting and the ready preview.
